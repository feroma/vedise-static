Utilizzo

Corrente: aria-current="page" · disabilitato: aria-disabled="true" · compatibile con il markup di paginate_links() di WordPress (.page-numbers, .current, .dots)

<nav class="pagination" aria-label="Paginazione">
  <a class="pagination__item pagination__item--prev" href="?pg=1">
    <span class="icon" aria-hidden="true">chevron_left</span>
    <span class="visually-hidden">Pagina precedente</span>
  </a>
  <a class="pagination__item" href="?pg=1">1</a>
  <span class="pagination__item" aria-current="page">2</span>
  <a class="pagination__item" href="?pg=3">3</a>
  <span class="pagination__item pagination__item--dots" aria-hidden="true">…</span>
  <a class="pagination__item" href="?pg=12">12</a>
  <a class="pagination__item pagination__item--next" href="?pg=3">
    <span class="icon" aria-hidden="true">chevron_right</span>
    <span class="visually-hidden">Pagina successiva</span>
  </a>
</nav>

Icone

Google Material Symbols, stile Outlined, font variabile in self-hosting. L'icona si scrive con il suo nome dentro un elemento con classe .icon; nel catalogo un clic copia il codice · base/_icons.scss

Utilizzo

aria-hidden="true" per le icone decorative; per un'icona da sola dentro un link o un bottone aggiungi un testo per gli screen reader

<span class="icon" aria-hidden="true">arrow_forward</span>

    <!-- icona + testo -->
    <a class="icon-text" href="#">Scopri di più <span class="icon icon--text" aria-hidden="true">arrow_forward</span></a>

    <!-- solo icona -->
    <button type="button">
      <span class="icon" aria-hidden="true">search</span>
      <span class="visually-hidden">Cerca</span>
    </button>
